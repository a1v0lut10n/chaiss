# Release 0.3.0 published to crates.io

- **When:** 2026-08-30 11:13:44 local
- **Type:** execution
- **Project:** chaiss

## Context

Minor-version bump covering PR #40: plain-language LLM outage messages (with
the raw backend detail logged to the console), `gemini-3.7-flash` as the
default Google model, the `LLM_MODEL` override, and the `GEMINI_API_KEY`
alias. Minor rather than patch because
`chaiss-core::llm::stream_llm_response` changed its return type to the new
`LlmError`.

## Details

`chaiss-core` 0.3.0 and `chaiss` 0.3.0 published in dependency order with
`SQLX_OFFLINE=true` from a synced `main`; `chaiss` was verified against
the registry copy of `chaiss-core` 0.3.0 before upload. As with 0.2.0, the
annotated tag `v0.3.0` was created on the release commit (`bc4c1ef`)
before the merge of PR #41, and the CHANGELOG section landed in the release
PR. The `chacha20 v0.10.0` yanked-lockfile warning is cosmetic (lockfiles
are not shipped for library consumers) and is a candidate for a housekeeping
bump.
