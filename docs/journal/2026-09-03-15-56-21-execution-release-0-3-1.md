# 0.3.1 crates.io release

- **When:** 2026-09-03 15:56:21 local
- **Type:** execution
- **Project:** chaiss

## Context

Patch release carrying the chat panel table reflow fix (CHAI-0038, PR #44):
markdown pipe tables in LLM responses are reflowed into nested bullet lists,
and each chat message renders inside a horizontal scroll area, so wide
content can no longer corrupt the panel layout.

## Details

`chaiss` and `chaiss-core` bumped 0.3.0 → 0.3.1 in lockstep — a patch bump,
since the release contains only a bug fix with no public API change
(`chaiss-core` itself is unchanged and was bumped purely for the lockstep
policy). Release PR #45 carried the version bumps and the `## [0.3.1]`
CHANGELOG section; the annotated tag `v0.3.1` points at the release commit
`507ef68` and was pushed before the PR merged.

Published from a synced main in dependency order with `SQLX_OFFLINE=true`:
`chaiss-core` first, then `chaiss`, whose pre-publish verification compiled
against the registry copy of `chaiss-core` 0.3.1, confirming the published
dependency resolves cleanly.
