# Release 0.6.0 to crates.io

- **When:** 2026-10-31 16:36:18 local
- **Type:** execution
- **Project:** chaiss

## Context

colap published 0.3.0 and 0.4.0 a day apart, both breaking the API
chaiss read `.chaiss.cola` with, and three merged tickets were waiting
in `[Unreleased]`: the license files (CHAI-0049), the
`gemini-3.8-flash` default with the 402 billing message (CHAI-0048) and
the user guide refresh (CHAI-0047).

## Details

Taking stock found PR #70 already open from another session with the
colap migration under a reused ticket number (CHAI-0044) and the counter
moved backwards; it was the fuller implementation (startup diagnostics,
two more tests, the example updated), so it was renumbered to CHAI-0050
with a changelog entry and merged, and the duplicate PR #71 closed.
Release PR #72 bumped both crates 0.5.0 -> 0.6.0 in lockstep, folded
the changelog, and moved the yanked `clipboard-win` 5.4.1 to 5.4.3
after the dry run warned about it. Minor bump: a new default model and
stricter config parsing are behaviour changes. Published chaiss-core
then chaiss with `SQLX_OFFLINE=true`; the tarballs carry `LICENSE` and
`NOTICE` for the first time. Tag `v0.6.0` and the GitHub release carry
the changelog section.
