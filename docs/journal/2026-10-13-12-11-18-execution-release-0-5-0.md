# 0.5.0 crates.io release

- **When:** 2026-10-13 12:11:18 local
- **Type:** execution
- **Project:** chaiss

## Context

Minor release bundling the two features merged since 0.4.1:
`.chaiss.cola` naming the database file (CHAI-0045, PR #62) and the
Wayland app id plus `chaiss --install-desktop-entry` for the task bar
icon (CHAI-0046, PR #64). Minor rather than patch because both are
additions, matching the 0.4.0/0.4.1 precedent.

## Details

Release PR #65 bumped both crates 0.4.1 → 0.5.0 in lockstep and folded
the two Unreleased changelog sections, which had accumulated as
separate headings from the two tickets, into one 0.5.0 section. The
chaiss-core dry-run passed against the crate-local `.sqlx` cache; the
chaiss dry-run failed only on the not-yet-published dependency, as
expected, and its packaged file list included the new embedded logo
SVG. Published from a synced main with `SQLX_OFFLINE=true`,
chaiss-core first, then chaiss. Annotated tag `v0.5.0`; GitHub
release from the changelog section with crate links.

## Lesson

Each ticket adds its own `## [Unreleased]` heading when branched from
the same base; the release step must merge them, so check for
duplicate headings before promoting the section.
