# 0.3.2 crates.io release

- **When:** 2026-09-04 12:22:15 local
- **Type:** execution
- **Project:** chaiss

## Context

Patch release carrying the predictive-matrix castling fix (CHAI-0039,
PR #48): predicted-move arrows render again when the LLM's continuation
involves castling (`O-O`, `O-O-O`, and the digit forms `0-0`/`0-0-0`),
with parsing confined to the matrix line and game resume repairing
previously affected analyses without any database change.

## Details

`chaiss` and `chaiss-core` bumped 0.3.1 → 0.3.2 in lockstep — a patch
bump, since the release contains only a bug fix with no public API
change (`chaiss-core` itself is unchanged and was bumped purely for the
lockstep policy). Release PR #49 carried the version bumps and the
`## [0.3.2]` CHANGELOG section; the annotated tag `v0.3.2` points at
the release commit `9ca056e` and was pushed before the PR merged.

Published from a synced main in dependency order with
`SQLX_OFFLINE=true`: `chaiss-core` first, then `chaiss`, whose
pre-publish verification compiled against the registry copy of
`chaiss-core` 0.3.2, confirming the published dependency resolves
cleanly.
