# Release 0.2.0 published to crates.io

- **When:** 2026-08-06 17:59:19 local
- **Type:** execution
- **Project:** chaiss

## Context

First minor-version bump, covering the work of PRs #31–#37: egui 0.36,
per-game board-flip persistence (with automatic DB migration), formal move
undo, the design-token theme (roster cards, toolbar buttons), side-colored
depth-faded predictive arrows, the exploration-mode move-history strip, and
the NEXT-TICKET numbering convention.

## Details

`chaiss-core` 0.2.0 and `chaiss` 0.2.0 published in dependency order with
`SQLX_OFFLINE=true`. Unlike 0.1.7, the annotated tag `v0.2.0` was created on
the release commit (`92464e9`) before the merge of PR #38 rather than on the
merge commit afterward, and the CHANGELOG section landed in the release PR
itself. Publishing at 0.2.0 also resolves the cosmetic yanked-`spin` lockfile
warning that 0.1.7 tarballs carried.
